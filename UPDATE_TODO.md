# TODO: Fitur & Update KeiYomi

Daftar ini berisi saran fitur yang belum ditemukan dalam implementasi saat ini, berdasarkan fitur yang sudah ada.

## Fitur yang sudah ada (dipertahankan)
- Reading history
- Favorite / bookmark library items
- Search di library dan history
- Mode Webtoon / Normal
- Kualitas PDF ringan / asli
- Custom folder library
- Tema gelap / terang
- Bahasa Indonesia / Inggris
- Mode baca dan pembaca dokumen dasar
- Chapter management (tambah/edit/hapus)
- Backup/restore data lokal

## Prioritas fitur baru
1. Daftar isi / TOC otomatis untuk EPUB dan PDF
2. Pencarian teks dalam dokumen yang lebih lengkap
3. Bookmark per halaman dan catatan / anotasi pembaca
4. Mode dua halaman (spread) untuk komik dan PDF
5. Fit width / fit height / fit page
6. Smart crop margin untuk komik/PDF
7. Auto-scroll dengan kontrol kecepatan
8. Tag, kategori, atau koleksi custom untuk library
9. Drag & drop impor file atau folder langsung ke aplikasi
10. Text-to-speech untuk dokumen berbasis teks
11. Export/import library dan progress ke file JSON atau backup portable
12. Mode portable khusus untuk dijalankan dari USB
13. Dukungan format tambahan seperti MOBI, CBR, MD

## Catatan
- Fokus implementasi berikutnya sebaiknya dimulai dari fitur pembaca lanjutan (TOC, bookmark, spread mode, smart crop) lalu lanjut ke manajemen perpustakaan.
- Fitur drag & drop dan export/import akan membuat aplikasi lebih mudah digunakan dan lebih mudah dibagikan antar perangkat.
